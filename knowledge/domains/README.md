# Domain Knowledge — OMAR OS

Reusable knowledge associated with a specific area. One subdirectory per domain is
recommended (e.g. `software-engineering/`, `ai/`, `digital-marketing/`, `thesis/`,
`real-estate/`).

Candidate domains from the brief: strategic planning, software engineering, AI, business
development, digital marketing, academic research, DBA/MBA thesis work, real estate.

**Rules:**
- Reusable across projects within the domain.
- Promote to `../core/` only when true across domains.
- Keep project-specific detail in `../../projects/`.

This folder is seeded empty (`.gitkeep`). Create a subdirectory when a domain's knowledge
warrants it.

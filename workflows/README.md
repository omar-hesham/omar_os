## How to use

- Start from [`../templates/workflow-template.md`](../templates/workflow-template.md) when
  adding a new workflow.
- Every workflow must respect the constitution ([`../PROJECT_CONSTITUTION.md`](../PROJECT_CONSTITUTION.md))
  and link to it rather than restating its rules.
